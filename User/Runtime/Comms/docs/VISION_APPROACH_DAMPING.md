# 物块追踪近距离减速

适用于普通03、04、24及51补抓对应入口。误差由视觉端计算：当前三角形ROI配置下，03和04都将检测框中心对准三角形尖顶上方50px的十字点（默认576×448画面约为(313,294)），24改用自己的抓取参考点。MCU不更改像素参考点，也不使用旧阶段坐标计算新阶段运动。MG90S在03（含补抓）为145°，进入04恢复140°。

## 纵向速度

- `|Y误差| ≤ 12px`：纵向停车，仍执行原X追踪和等待视觉事件逻辑。
- `12px < |Y误差| ≤ 80px`：03及补抓03的前进速度由100线性增加到150转/分；04及补抓04仍为70～100转/分；24及补抓24仍为40～70转/分。
- `80px < |Y误差| < 200px`：03及补抓03由150线性过渡到170；04仍由120线性过渡到150；24衔接段最低保持70，避免从近处70回落到原远处最低50。
- `|Y误差| ≥ 200px`：03及补抓03从200px处的170线性提升，在448px处达到200转/分；04仍为150～170；24及补抓24最高120不变。
- 03的近、中距离在80px处连续衔接；04中距离仍单独使用120转/分的起始下限，与近距离100转/分的终点分开，电机层沿用原速度平滑。
- 24在近区之外的前进输出不低于70，直到P输出超过它，再随误差增大至120；这不改变反向修正的原曲线和限幅。
- 03及补抓03调用层的纵向最高速度和单轮限幅均为200，04仍为170，避免调用层抵消PID设置；X修正仍最高±35，X死区仍为15px。
- 任何物块追踪的后退修正仍沿用原近距离20～40曲线并限幅30转/分，反向确认和坐标过期减速不变。差速后两轮共同限幅，实际纵向速度可能因转向饱和而降低。

没有修改06安全区追踪、02/12推散、34抓取、26投放等固定动作参数。03/04仍按远、中、近距离分段减速，原死区、后退确认和旧坐标减速保护保留。

## 反向确认与坐标有效期

前进过程中要求后退，或后退过程中要求前进，必须连续两帧不同序号的新坐标支持同方向；首次从停车启动后退同样确认。第一帧纵向输出0，第二帧才允许反向。同一帧在20ms控制任务中重复使用不计数。

误差回到死区清除候选，但保留已接受的方向；不同ID、更换阶段/补抓参考点、超过500ms的断帧不能混合计数。新任务和真正恢复入口清除PID及反向确认状态。短暂断帧不立刻重置整个PID。

原坐标年龄保护保持：250ms后逐渐减速，500ms停车。减速后不重新套用最低限速。视觉大幅Y跳变仅打印`[VY-JUMP]`，不直接丢弃；ID是类别而非同类物块的独立身份，目标锁定仍需视觉端处理。

## 调试

`[Y-REV]`打印状态、ID、序号、Y误差、请求速度、确认帧数及`WAIT_ZERO/ACCEPT`。`[03-T]`、`[S4-V]`和`[V]`坐标年龄日志保留。简写见`User/Runtime/Diagnostics/README.md`。请实车检查接近中心/ROI时是否逐渐减速，以及Y误差短暂变号是否仍会造成大幅前后移动。
