# UART2 简洁日志

UART2 保持 115200、8N1。周期记录仍为 750ms；状态变化、收发命令和故障立即记录。
只缩短打印文字，不改变视觉协议、动作、PID 或超时。

```text
[ST] 24 TRACK
[04] RX14 STOP, TX14, WAIT RX02/24/E4
[03] id=5 x=12 y=80 u=4 v=100 w=96/104 act=95/103
[YAW] s=64 r=26.18 f=25.86
[V] s=64 id=5 q=31 age=26726 ok=0 why=FAULT w=0/0
[SIDE] field=14500 v=120 ms=854 dist=209%
[BOOT] rst=PIN f=14000000
```

## 字段

- `RX04` / `TX04`：MCU 收到 / 发出十六进制命令 04，不重复打印固定包头包尾。
- `s`：内部状态枚举值；`[ST]`：状态变化说明。两者不是同一套编号，协议阶段看 `[ST]`。
- `id`：物块类别；`cmd`：目标选择命令；`q`：坐标序号；`age`：坐标年龄，毫秒；`ok`：有效性，1/0。
- `x/y`：视觉像素误差；`u/v`：转向 / 纵向速度；`w`：左右轮指令；`act`：左右轮实测速度，均为转/分。
- `r`：原始 Yaw；`f/field`：扣除启动零点后的场地角度；`z/zero`：启动零点；`g/goal`：目标角度；`e`：角度误差。
- `[YAW]`、`[ANGLE]`、`[GOAL]` 及带小数的角度是度；其余整数角度是百分之一度，例如 `14500` = 145°。
- `ms/wait/age/tmo`：毫秒；`n`：次数；`FWD=速度/时间`、`back=速度/时间`：转/分、毫秒。
- `L/R`：左 / 右；`CW/CCW`：顺 / 逆时针；`UP/DOWN`：抬 / 放框；`WIDE/NEAR`：广 / 近视角。
- `[SIDE]`：侧移；`[CORNER]`：角落撤离；`[6E]`：安全区恢复；`[SUPP]`：补抓；`[LOAD05]/[CHECK05]`：载荷复检。

## 停车/等待原因 `why`

`OLD` 坐标过期；`NONE` 无坐标；`SLOW` 断帧减速；`XY` 坐标对准保持；`PID` 正常追踪；
`CHECK05` 等复检结果；`RX05` 等复检握手；`LIMIT05` 补抓预算耗尽等最终复检；
`WIDE` 等广角稳定；`ACK` 等阶段握手；`FRAME` 等框动作；`FAULT` 故障停车；
`IDLE` 未启动/已停止；`HOLD` 当前阶段保持；`MOVE` 定时/角度动作。

## 复位原因 `rst`

`POR` 上电；`BOR` 欠压；`PIN` 外部复位；`SW` 软件复位；`IWDG/WWDG` 看门狗；
`LP` 低功耗复位；`?` 未知；`NA` 未捕获。`f` 在 `[BOOT]` 中是原始复位标志，不是场地角度。

`[IMU] src=JY901S` 仍表示选择了兼容驱动，不保证实物型号是 JY901S；
`ver/pid` 保留供型号识别诊断。HWT101 命令发送成功仍不代表收到传感器 ACK。
