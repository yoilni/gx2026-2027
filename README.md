# gx_version1

基于 STM32F407ZGT6 和 STM32 HAL 库的 M2006 电机 CAN 控制实验工程。

## 当前功能

- 使用 CAN1 与大疆 M2006 电调通信。
- CAN1 使用 PB8（RX）和 PB9（TX），总线速率为 1 Mbps。
- 接收电机 1–4 的反馈帧（CAN ID `0x201`–`0x204`）。
- 向 CAN ID `0x200` 发送四路电机电流控制指令。
- CAN 硬件过滤器仅接收 `0x201`–`0x204`，并启用自动重发和总线关闭自动恢复。
- 任一电机反馈超过 100 ms 未更新时，该路立即输出零电流并清空 PID 状态。
- 左右速度接口按电机 1/4 为左侧、2/3 为右侧映射；制动时四路同步切换目标和电流上限。
- 使用 FreeRTOS 高优先级任务，每 2 ms 执行一次 M2006 速度环 PID 控制。
- 使用 FreeRTOS 低优先级任务，每 200 ms 刷新一次 JY901S 姿态 OLED 显示。
- JY901S 姿态超过 500 ms 未更新时，OLED 显示 `OFFLINE`，恢复通信后自动恢复角度显示。
- 默认任务每 500 ms 翻转一次 PC13 LED（完整闪烁周期为 1 秒）。

## 当前电机设置

启动目标在 `Core/Src/main.c` 中设置：

```c
SpeedLoop_SetMotorTarget(4U, 0.0f, 1000);
```

参数依次为：`电机编号（1–4）`、`减速箱输出轴目标转速（rpm）`、`最大控制电流`。

当前设置为电机 4 停止。若需让电机 1 以 10 rpm 转动，可修改为：

```c
SpeedLoop_SetMotorTarget(1U, 10.0f, 1000);
```

## 接线与使用注意

- MCU 的 PB8/PB9 不能直接连接 CANH/CANL，必须经 CAN 收发器连接。
- CAN 总线两端应配置 120 Ω 终端电阻。
- M2006 电调需要独立、可靠的电源供应。
- 下载/复位 MCU 时，程序停止发送 CAN 电流指令；如需避免下载瞬间的意外动作，建议在硬件上使用 CAN 收发器的 `EN`/`STB` 引脚实现默认静默。

## 构建

使用项目的 CMake 配置构建：

```powershell
cmake --build cmake-build-stm32 --parallel 4
```

生成的固件为 `cmake-build-stm32/gx_version1.elf`。

## FreeRTOS 任务文件结构

- `Core/Src/freertos.c` 仅保存任务属性、句柄和创建逻辑。
- `OLED/oled_task.c` 定义 OLED 初始化、显示逻辑和 OLED 任务入口。
- `M2006/M2006_task.c` 定义 2 ms 电机控制任务入口。
- `Core/Src/led_task.c` 定义状态灯任务入口。
- 各 `_task.h` 使用外部声明，将任务入口提供给 `freertos.c`。

### 2026-08-31 — 外设任务实现模块化

- `freertos.c` 只负责配置和创建任务，具体任务入口移动到各自的 `_task.c`。
- OLED 初始化、姿态格式化以及在线/离线显示从 `main.c` 移至 `OLED/oled_task.c`。
- M2006 周期控制和 LED 周期任务分别移至 `M2006/M2006_task.c` 与 `Core/Src/led_task.c`。
- JY901S UART HAL 回调从 `main.c` 移至 JY901S 模块。
- `main.c` 仅保留系统初始化、外设模块初始化和调度器启动流程。

### 2026-08-31 — 同步制动并增加姿态断线显示

- 修复左右速度参数被忽略以及四路电流限幅不一致的问题。
- 电机 1/4 映射为左侧、电机 2/3 映射为右侧；制动更新在临界区内原子完成。
- 切换目标时清空对应 PID 动态状态，避免旧积分影响制动起始时刻。
- JY901S 姿态超过 500 ms 未更新时判定离线，OLED 清除旧角度并显示 `OFFLINE`。
- JY901S 恢复输出后，OLED 自动切回 `ONLINE` 和实时姿态。

### 2026-08-31 — 加强 CAN 总线与电机失联保护

- 启用 CAN 自动重发和总线关闭自动恢复，并同步更新 CubeMX 配置。
- 将接收过滤器限制为四路 M2006 反馈 ID `0x201`–`0x204`。
- 为每路反馈记录接收时间；超过 100 ms 未收到反馈时发送零电流并复位该路 PID。
- 发送邮箱拥塞时丢弃排队的旧控制帧，下一控制周期重发最新指令。
- 首帧反馈自动建立角度零点，避免上电角度跨圈误判。

### 2026-08-31 — 控制与显示逻辑迁移至 FreeRTOS 任务

- 将 M2006 速度环迁移到高优先级、2 ms 周期任务。
- 将阻塞式 OLED 刷新迁移到低优先级、200 ms 周期任务，避免阻塞电机控制。
- 将 PC13 状态灯迁移到默认任务，以 500 ms 周期翻转。
- 删除 `osKernelStart()` 后不可达的主循环调度代码。
