# 物块追踪近距离减速

适用于普通03、04、24及51补抓对应入口；坐标仍是视觉当前阶段选定参考点的误差：03/04的画面中心、24的框内ROI参考点。MCU不更改参考点，也不使用旧阶段坐标计算新阶段运动。

## 纵向速度

- `|Y误差| ≤ 12px`：纵向停车，仍执行原X追踪和等待视觉事件逻辑。
- `12px < |Y误差| ≤ 80px`：03/04/24及补抓对应参考的前进速度均由40线性增加到70转/分。
- `80px < |Y误差| < 200px`：03/04由70平滑过渡到远处最低120；24衔接段最低保持70，避免从近处70回落到原远处最低50。
- `|Y误差| ≥ 200px`：03/04及补抓对应参考均最低120、最高150；24及补抓24最高120不变。
- 24在近区之外的前进输出不低于70，直到P输出超过它，再随误差增大至120；这不改变反向修正的原曲线和限幅。
- 04调用层的纵向最高速度和单轮限幅均同步提高到150，避免旧70/90限幅抵消PID设置。03单轮限幅仍150，X修正仍最高±35。
- 任何物块追踪的后退修正仍沿用原近距离20～40曲线并限幅30转/分，反向确认和坐标过期减速不变。差速后两轮共同限幅，实际纵向速度可能因转向饱和而降低。

没有修改06安全区追踪、02/12推散、34抓取、26投放等固定动作参数。此次不是全程降低速度，而是避免近处小误差被高最低限速放大。

## 反向确认与坐标有效期

前进过程中要求后退，或后退过程中要求前进，必须连续两帧不同序号的新坐标支持同方向；首次从停车启动后退同样确认。第一帧纵向输出0，第二帧才允许反向。同一帧在20ms控制任务中重复使用不计数。

误差回到死区清除候选，但保留已接受的方向；不同ID、更换阶段/补抓参考点、超过500ms的断帧不能混合计数。新任务和真正恢复入口清除PID及反向确认状态。短暂断帧不立刻重置整个PID。

原坐标年龄保护保持：250ms后逐渐减速，500ms停车。减速后不重新套用最低限速。视觉大幅Y跳变仅打印`[VY-JUMP]`，不直接丢弃；ID是类别而非同类物块的独立身份，目标锁定仍需视觉端处理。

## 调试
