# 26投放前角落检查

视觉命令仍为`F1 F2 26 1F 2F`，不新增触发命令或26应答。

MCU在开始最终投放前，按收到26时的当前场地角度检查现有角落撤离规则：

- 满足范围，且本载荷尚未完成撤离：消费本次26，先执行角落撤离。
- 不满足范围，或本载荷已经完成撤离：执行原最终对正和投放。
- 此检查不等待1秒视觉追踪，不要求有效坐标或X对准；普通16追踪后的角度判断仍保留1秒条件。
- 26只额外允许角落撤离，不重新允许普通侧方横移。
- 场地角度仍按PE12启动零点、出发区及红蓝方换算，角度范围不变。

同一个入口适用于06搜索、追踪、6E、36、追踪超时后退，以及46应答后恢复追踪收到的26。

## 普通侧移期间的26

- 普通侧移的转侧方、定时前进、转回安全区期间收到26，只锁存一次，不直接跳入投放、不重新计时；重复26合并。
- 有暂存26时，侧方前进为120转/分，总时长限为200ms，从原前进起点计时；没有26时按角度计算408～1225ms。若前进中才收到26且已超过200ms，就结束前进并转回安全区，不再追加200ms；返回阶段收到26不补做前进。
- 必须完成“转到侧向 → 前进段 → 转回安全区”，然后消费暂存26，进入上述角落检查及正常投放入口。按完成时的当前Yaw判断，不使用收到26时的侧向Yaw。
- 不要求视觉重发26、不新增26应答，也不再额外等待1秒视觉追踪；若未收到26，侧移完成后仍按原流程重新累计1秒追踪。
- 保留原转向到位/2秒软超时、硬件故障和停车保护。05复检仍可取消当前侧移及旧26；不会强行完成动作后投放。
- 旧`REPOSITION_FACE_SAFE`状态在有暂存26时，也先转回安全区再处理；角落撤离期间丢弃26、复检后需要新26的规则不变。

## 正常投放参数

收到06进入找区时，MG90S切到145°，关闭PA2挡板PWM，PA3夹爪闭合到36°并持续输出PWM。接收16并切入安全区追踪时恢复PA2 PWM，下达155°放挡板指令，150ms后关闭PA2 PWM，期间不等待舵机、继续处理坐标和运动。26顶边定位和第一次后退时持续输出155° PWM，第二次前进前将PA2抬起1/3行程至130°。第二次前进结束后全抬到80°，下达指令后立即后退。

不需要撤离时：转正安全区 → 闭爪、70转/分前进750ms顶边定位 → 张开夹爪（物资74°、伤员73°），同时70转/分后退250ms → 抬挡板到130°，不额外等待 → 70转/分前进700ms → 停车、全抬挡板到80° → 立即以100转/分后退700ms → 闭爪36°并旋转180°（角度PID40～80转/分）。转向结束后切到145°的03物块搜索视角，按原角度张开夹爪（物资62°、伤员63°），立即下达PA2放下155°的指令并进入07。从下达放挡板指令起计500ms，期满才闭合夹爪36°；计时不阻塞07搜索或行驶。

前后退仍使用航向角度环，最终后退单轮限幅200转/分，其余三段限幅170转/分。两段前进分别累计实际下达前进指令的750/700ms；偏差超过10°仍边走边纠偏，达到90°才暂停前进、原地纠偏。走满后若仍超过10°，原地纠偏到范围内才允许正常进入下一段。任一前进阶段满3秒仍未完成，停止推进、先下达张爪指令（物资74°、伤员73°）并全抬挡板，不加舵机等待，以超时时的实际航向后退100转/分700ms，再闭爪、转180°进入07，不计为成功投放。急停、硬件故障保护不变。两段推进和全抬挡板均正常完成后，本趟只记一次投放。
保留车轮平滑加减速、转向近目标减速及每段2秒转向上限；仅最后180°的到位死区扩大为±10°，其它转向仍为±4°。
最后180°进入±10°后仍停车确认200ms。此确认与挡板的500ms预留时间是两件事：确认转向结束后立即下达放挡板指令并发送11/03或51/03。若2秒转向软超时，也按相同方式接07，不伪造实际yaw。
500ms内的普通闭爪请求不会提前写PWM；若新的抓取阶段要求张开夹爪，取消旧的定时闭合，不让它打断抓取。
实际距离仍受加减速、打滑和载荷影响，配置时间包含平滑加速过程。

## 撤离后继续

撤离动作：转向安全区反方向、120rpm前进600ms，转向对应侧向、120rpm前进600ms，转回安全区，MCU发05。两段前进保留原航向角度环。

视觉收到05后，仍回05并复检；合格时发载荷ID和06，需要整理时发02，无合格载荷时发24。
复检后找安全区并满足条件时，视觉需发送新的26；MCU不自动重放撤离前的26。

撤离期间重复26仍忽略，不打断动作、不延后执行；旧半帧隔离、05优先和硬件故障保护不变。
同一载荷完成撤离后不重复撤离；新抓取重置该保护。
