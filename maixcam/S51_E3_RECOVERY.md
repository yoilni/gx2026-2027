# 普通51黑／绿03任务的E3恢复

仅适用于07之后的普通51黑／绿03搜索，不改变红色任务、首次绿色任务或51补抓预算及恢复动作。

| 本轮有效E3恢复次数 | 动作 |
| --- | --- |
| 第一次 | 80转/分后退800ms，然后用陀螺仪累计逆时针旋转360°搜索 |
| 第二次 | 转到安全区反方向，100转/分前进1200ms，然后用陀螺仪累计逆时针旋转360°搜索 |
| 第三次及之后 | 保留原恢复动作：80转/分后退800ms，再逆时针旋转360° |

安全区反方向为已按启动零点、出发区和红蓝方换算的安全区目标角度加180°，再归一化到0～360°。前进1200ms从转向到位并稳定200ms后，或定点转向达到2000ms上限后开始，不包含转向时间。

计数只在接收E3且真正启动新恢复时增加；动作期间重复E3、与有效新坐标同时出现的E3，以及无消息触发的静默恢复均不计数。短暂重新找到目标不会清零；初始化新03任务或停止、故障、重置时清零。

转向、前进及360°搜索均非阻塞，串口解析持续运行；有效、新鲜的ID5/ID6坐标可打断恢复，直接续接03追踪，不重发51、03。其他类别或超过500ms的坐标不能打断。陀螺仪、电机与急停故障仍停车；定点转向2000ms超时后按要求停车并继续前进段，记录真实角度而不伪造到位，360°搜索沿用20秒超时。

串口打印`[S51-E3] RX E3 count=...`以及第二次恢复的原始目标角度、场地角度和前进参数。现有通信格式不变，不增加新的视觉握手命令。

## 22后的51/03入口

07之后整理结束回22，收到E2切换51/03后，等待或后退/左45°/右90°期间收到E3，直接交给上述普通03恢复策略，不再当作等待22回复的未知事件。切换后第一条有效E3按第一次策略处理，下一次有效E3按第二次策略；新鲜ID5/ID6坐标与E3同时到来时直接续接03，旧E3不消耗恢复次数。

没有E3也没有坐标时，短程扫视最多失败两轮。第一次完成后保留原5秒等待窗口，再扫一次；第二次结束立刻升级为普通03的80转/分后退800ms、陀螺仪累计逆时针360°搜索。升级不发送51/03、不计作额外E3；坐标仍可打断，360°保持20秒超时。单段定点转向继续使用2秒上限。实际短程失败次数打印`[S4-22E2] SWEEP FAILED`和`UPGRADE NORMAL03 CCW360`。

该限制针对已经切换51/03的入口；第一次绿色任务的22/E2协议及禁止切换目标限制保持不变。

## 03入口框位

普通03初始化、22后转51/03，以及51补抓的独立03入口，在发命令前先下达完全放框指令（左204°、右23°），不等待目标坐标、不增加舵机等待延时。07旋转期间提前发送的11/03为准备搜索，是这条规则的例外：保持抬框直至180°旋转结束。

26投放结束先全抬框并后退100转/分300ms；后退结束先发11/03并保持抬框旋转180°，旋转结束后再完全放框，即使没有红色坐标也放框。保留原有2秒转向上限；到位或超时结束均放框。新鲜红色坐标提前打断旋转时，先停车放框，再转入03追踪。放框不清理待处理E3/04、不新增延时。03丢失恢复沿用放框位置，24仍只抬至比放框高20°；51补抓的已有载荷记录、次数及15秒预算保持不变。PWM放框调用失败时停车进入故障，不继续转入搜索/追踪。
